# Expert Rating Guide

Use the link and evaluation materials provided by the research team. You do not
need to install anything or create a GitHub account.

## Start and complete your evaluation

1. Open the app link in your browser and enter your assigned evaluator code.
2. Select **Bewertungspaket öffnen** (Open evaluation packet) and choose the
   packet file provided by the research team.
3. Work through the cases and task tabs, following the instructions and rubric
   shown in the app. You can move between cases and change answers before you
   finish. An unanswered item is not counted as a zero.
4. When finished, select **Bewertungen exportieren** (Export ratings) and save
   the downloaded `ratings-evaluation.json` file.
5. Send that ratings file to the research team using the secure method they
   provided. The app does not send it automatically. Keep the file until the
   team confirms it arrived.

## Versioned document-rubric packets

New document-rubric 1.2.0 packets show the seven permitted document scores and
the complete assessment principles under **Bewertungsraster**. Segment modelling
labels are A/B/C, not document scores; candidate counts and distinct-segment
counts describe different units. Historical packets and saved sessions remain
readable.

Generated evidence synthesis is stored separately and hidden by default. It
can appear in its own collapsible panel only for explicitly released Task B
packets (`synthesis_display_allowed=true`). It is never available during
independent reference scoring or feedback-quality scoring. Do not alter packet
visibility flags without an approved study-protocol decision.

## Pause and resume

Your work is saved automatically in the browser on the device where you are
working. You do not have to finish in one sitting. When you return, open the
same app link, enter the same evaluator code, and open the same packet. If asked
whether to continue or start again, choose **Fortsetzen** (Continue).

For extra protection, or to move to another device, select **Stand exportieren**
(Export session) and save the session file. On the other device, open the app,
enter the same evaluator code, and use **Bewertungspaket öffnen** to select that
session file. Choose **Fortsetzen** if prompted. A session file is a backup for
continuing your work; it is not the final ratings file to send to the team.

Do not clear browser data before exporting your completed ratings. If you see a
message that your work was not saved, export the session file before closing
the page.
